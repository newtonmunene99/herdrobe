# Security

Herdr mods are trusted code: they can run programs and read files as you. Each layout's README
lists what its mods run and whether anything reaches the network. Read it, and the mods, before
installing.

If a mod here does something it shouldn't (runs a command from untrusted input, writes outside
where it says, leaks a path or token), please report it privately through
[GitHub's private vulnerability reporting](https://github.com/newtonmunene99/herdrobe/security/advisories/new)
rather than a public issue.
